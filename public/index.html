How it works
When you click Generate AI Insights or Generate Improvement Plan, the dashboard sends your portfolio data to the Claude API and returns structured analysis. Your API key is stored only in your browser — it never touches our servers. Typical cost per analysis: $0.003–0.008 USD (less than 1 cent).
OPTION 1 Direct API Key — Anthropic or OpenAI
Step-by-step setup
1
Go to console.anthropic.com/settings/keys and sign in (or create a free account)
2
Click Create Key, name it altudo-dashboard, and click Create Key
3
Copy the key — it starts with sk-ant-... — you only see it once
4
Paste it below and click Save & Activate
🔒 Stored only in your browser localStorage. Never sent to any server other than the AI provider directly.
✨ Also works with OpenAI: Paste a key starting with sk- from platform.openai.com/api-keys — the dashboard auto-detects it and routes to GPT-4o. Anthropic keys (sk-ant-...) use Claude Sonnet 4.
